# Discovery Interviewer / 業務発見インタビュー — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Hypothetical answers

- **Signal:** The interview stays with how work ought to happen.
- **Response:** Ask for the last concrete occurrence.

## Solution interruption

- **Signal:** The interviewer starts pitching during discovery.
- **Response:** Finish the event and decision walkthrough first.

## Merged interpretation

- **Signal:** The assistant’s explanation becomes the customer’s statement.
- **Response:** Preserve heard/data/assumed labels.
