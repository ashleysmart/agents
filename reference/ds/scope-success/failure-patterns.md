# Scope & Success Designer / スコープ・成功条件 — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Accuracy-only done

- **Signal:** A model score is used as the whole customer outcome.
- **Response:** Keep technical acceptance and changed business work as distinct linked criteria.

## Scope cutting removes value

- **Signal:** The first step is smaller but no longer changes anything useful.
- **Response:** Recheck the decision and value chain.

## Premature promise

- **Signal:** Dates are committed before data and permission dependencies are known.
- **Response:** Expose dependency owners and uncertainty before estimating.
