# Scope & Success Designer / スコープ・成功条件 — worksheet / ワークシート

- **Use:** fill this worksheet with the user’s evidence.
- **Unknowns:** retain “Not supplied” until information is available.
- **Status:** distinguish proposed content from an agreed decision.

| Section | What to record | Working content |
|---|---|---|
| Problem and urgency | Affected role; scale; consequence; timing; metric owner; evidence labels. | Not supplied |
| First step | Workflow; team; intended measurable change. | Not supplied |
| Boundaries | In; Out; Not now; rationale for each boundary. | Not supplied |
| Feasibility | Data; access; permission; effort; owner role; evidence/status. | Not supplied |
| Done | Before/after; changed decision and role; metric/source/baseline; usage cadence; customer/delivery maintenance owners. | Not supplied |
| Handoff questions | Question; effect on delivery; role able to answer; priority. | Not supplied |

## Before handoff / 引き継ぎ前

- The first step changes a decision or workflow.
- Done can be measured with a defined source and owner.
- The FDE can identify both the build and remaining blockers.
