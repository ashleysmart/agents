# Ownership & Handoff Designer / 責任分担・引き継ぎ — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Everyone owns it

- **Signal:** A team name hides the missing accountable role.
- **Response:** Identify an accountable outcome owner.

## Decider equals doer

- **Signal:** The person performing the task is assumed to own the decision.
- **Response:** Record decision and delivery separately.

## Imported org chart

- **Signal:** A reference company’s roles become mandatory locally.
- **Response:** Treat the model as a starting point and test actual boundaries.
