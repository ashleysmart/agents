# Product Opportunity Scout / 製品化機会の探索 — worksheet / ワークシート

- **Use:** fill this worksheet with the user’s evidence.
- **Unknowns:** retain “Not supplied” until information is available.
- **Status:** distinguish proposed content from an agreed decision.

| Section | What to record | Working content |
|---|---|---|
| Request evidence | Customer alias/type; request wording; underlying need; source; date. | Not supplied |
| Classification | Standard / bespoke / candidate / unknown; reason; capability evidence. | Not supplied |
| Reuse case | Distinct account count; repeated work; supplied effort; transparent calculation. | Not supplied |
| Candidate note | Need; who; what was done; value of reuse; suggested owner; decision requested. | Not supplied |
| Next validation | Missing evidence; role able to answer; specific check. | Not supplied |

## Before handoff / 引き継ぎ前

- Classification includes evidence and uncertainty.
- Account counts represent distinct supplied accounts.
- No roadmap promise is implied by a candidate note.
