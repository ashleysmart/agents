# Product Opportunity Scout / 製品化機会の探索 — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Request count inflation

- **Signal:** Several requests from one customer are counted as several customers.
- **Response:** Deduplicate by account before assessing recurrence.

## Three means build

- **Signal:** A heuristic becomes an automatic roadmap commitment.
- **Response:** Present the evidence for product review.

## Same wording, different need

- **Signal:** Similar feature names hide incompatible business rules.
- **Response:** Compare the underlying work and rules before grouping.
