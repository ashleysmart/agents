# Account Growth Planner / アカウント成長計画 — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Upsell list

- **Signal:** The plan lists more features without a shared foundation.
- **Response:** Show the reuse dependency for each next layer.

## Imagined demand

- **Signal:** A next layer has no customer role asking for its outcome.
- **Response:** Find the value owner and validate the need.

## Installed means useful

- **Signal:** Growth starts from software that nobody actually uses.
- **Response:** Check adoption and the present outcome first.
