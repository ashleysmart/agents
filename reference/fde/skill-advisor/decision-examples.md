# Choosing the next move / 次の一手の判断例

- **Use:** compare the current gap and requested artifact with these illustrative situations.
- **Boundary:** these examples guide judgment; they do not require every engagement to run every skill.

## Distinguish nearby choices / 似た場面を区別する

- **Murderboard versus readiness:** challenge a proposal's claims with Murderboard; establish whether the intended operation is supported with readiness review.
- **Scope versus deployment planning:** scope decides which useful outcome to commit; planning decides how to deliver that agreed work.
- **Conversation rehearsal versus stakeholder planning:** rehearse an explanation when the audience and issue are known; map access/influence when the decision network is the gap.
- **Growth versus product scouting:** growth asks what this customer should do next; product scouting asks what shared need merits a product decision.
- **Ontology design versus direct editing:** design when meaning or answer paths are unclear; use an available validated editing tool for an explicit supported graph edit.
- **Configure versus invent:** verify existing behavior before creating custom work; some accounts need enablement, not a new build.

## Examples / 例

- **“Build us a dashboard; we cannot explain what decision it changes.”** Start with Discovery Interviewer, then value exploration once the work is understood; defer design commitments.
- **“Our pilot has high accuracy, but staff still check everything manually.”** Start with DS Scope Checker to inspect the changed decision, measure, users, and owner; use discovery if the real workflow is still unknown; do not assume the answer is a better model.
- **“The executive proposal is tomorrow and we have a draft.”** Start with a presentation Murderboard; record weak claims and evidence gaps; avoid restarting broad discovery unless those gaps undermine the decision case.
- **“We have spent days waiting for access.”** Start with a specific escalation request naming attempts, need, owner, date, and consequence; do not run a whole steering workshop just to ask for access.
- **“Three accounts asked for this.”** Start with product-opportunity analysis, checking distinct accounts, underlying need, existing capability, and repeated effort; defer a roadmap commitment.
- **“Run a Murderboard of this design.”** Respect the chosen skill; ask only the preparation questions it needs rather than forcing the user through the advisor.
