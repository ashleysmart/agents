# Murderboard / マーダーボード — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Theatre

- **Signal:** Reviewers ask difficult-sounding questions unrelated to the decision.
- **Response:** Tie each question to a claim, failure consequence, or decision.

## Confident answer accepted as proof

- **Signal:** A fluent answer closes an item without evidence.
- **Response:** Record the test, observation, or document that supports the answer.

## AI approval

- **Signal:** An assistant verdict is presented as permission to launch.
- **Response:** Keep the recommendation separate from the accountable human decision.

## No closure

- **Signal:** The board ends with a list of concerns nobody owns.
- **Response:** Assign an owner, date, and closure condition to each open item.
