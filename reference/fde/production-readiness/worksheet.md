# Production Readiness Review / 本番準備レビュー — worksheet / ワークシート

- **Use:** fill this worksheet with the user’s evidence.
- **Unknowns:** retain “Not supplied” until information is available.
- **Status:** distinguish proposed content from an agreed decision.

| Section | What to record | Working content |
|---|---|---|
| Prototype strengths | Observed behavior; conditions; supporting evidence. | Not supplied |
| Gap register | Layer; gap; consequence; category; owner; verification task. | Not supplied |
| Evidence | Test or log; version/date; expected result; actual result; limitations. | Not supplied |
| Operations | Customer owner; delivery owner; update path; failure response; ongoing cost assumptions. | Not supplied |
| Recommendation | Ready within stated scope / gaps remain / insufficient evidence; rationale; next action. | Not supplied |

## Before handoff / 引き継ぎ前

- Each readiness claim has evidence or an explicit unknown.
- Customer-specific work is distinguished from platform behavior.
- Operational ownership extends beyond go-live.
