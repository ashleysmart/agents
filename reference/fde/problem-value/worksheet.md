# Problem & Value Explorer / 課題・価値の探索 — worksheet / ワークシート

- **Use:** fill this worksheet with the user’s evidence.
- **Unknowns:** retain “Not supplied” until information is available.
- **Status:** distinguish proposed content from an agreed decision.

| Section | What to record | Working content |
|---|---|---|
| Symptom | Original wording; affected role; event or observation. | Not supplied |
| Cause branches | Cause; effect; supporting observation; uncertainty; next test. | Not supplied |
| Value chain | Operational change; business consequence; affected owner role. | Not supplied |
| KPI definitions | Level; metric; unit; formula; population; period; source; baseline or collection plan; owner. | Not supplied |
| Value claim | Calculation using supplied inputs; assumptions; limitations; validation owner. | Not supplied |

## Before handoff / 引き継ぎ前

- Each causal link is supported or labeled assumed.
- Impact has a customer owner.
- Baseline gaps and units are explicit.
