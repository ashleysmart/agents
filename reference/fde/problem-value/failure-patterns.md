# Problem & Value Explorer / 課題・価値の探索 — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Five-why tunnel

- **Signal:** One chain is forced despite multiple causes.
- **Response:** Branch the investigation and test each branch.

## Activity sold as impact

- **Signal:** Usage or runs are treated as customer value.
- **Response:** Show the intermediate outcome and the business measure.

## Invented baseline

- **Signal:** A target or saving is stated without input data.
- **Response:** Leave a baseline gap and define how to collect it.

## Causal leap

- **Signal:** A correlation or plausible story is called proven impact.
- **Response:** State the hypothesis and the evidence needed to test it.
