# Decision Advisor / 判断の整理 — failure patterns / 失敗パターン

- **Use:** identify a concrete observation before applying a pattern.
- **Finding:** name the consequence and the next useful check.
- **Uncertainty:** absence of evidence is not proof that a failure occurred.

## Universal permission gate

- **Signal:** Routine authorized work is stopped by a method matrix.
- **Response:** Apply real project rules and existing authorization.

## Reversible claimed, untested

- **Signal:** Undo is assumed without knowing persistence or downstream effects.
- **Response:** Check the restore path and affected systems.

## Silent waiting

- **Signal:** Work waits without a precise help request.
- **Response:** Draft the need, owner, date, and consequence.
