## Choosing when to use them / 使う時期

- [Skill selection and lifecycle guidance](skill-advisor/index.md) connects the methods to the current gap and next decision.
- [Advise me](../../skills/ADVISE_ME.md) recommends a primary skill and a conditional handoff.

## Shared work / 連携

- Discovery produces evidence for problem/value exploration and ontology design.
- Value exploration supplies measures for scoping, steering, and account growth.
- Ownership and scoping supply a buildable handoff for deployment planning.
- Murderboard challenges the proposed design; readiness review checks the intended deployment conditions.
- Growth and product scouting reuse observed work without committing new scope automatically.
- Tool identity does not require a separate agent personality for every tool.
