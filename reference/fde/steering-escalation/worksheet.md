# Steering & Escalation Planner / 運営会議・エスカレーション — worksheet / ワークシート

- **Use:** fill this worksheet with the user’s evidence.
- **Unknowns:** retain “Not supplied” until information is available.
- **Status:** distinguish proposed content from an agreed decision.

| Section | What to record | Working content |
|---|---|---|
| Steering brief | Purpose; value evidence; attendees by role; decisions requested. | Not supplied |
| Agenda | Suggested timebox; topic; evidence; decision owner; desired result. | Not supplied |
| Escalation draft | Situation; attempts; need; from whom; by when; consequence. | Not supplied |
| Opportunity brief | Observed unmet need; value hypothesis; scope implication; next validation. | Not supplied |
| Decision log | Decision; rationale; owner; follow-up; date. | Not supplied |

## Before handoff / 引き継ぎ前

- Each requested decision has an owner and evidence.
- A blocker message is actionable.
- No message has been sent by merely drafting it.
