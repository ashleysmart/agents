# Ontology Builder Wizard / オントロジー設計 — worksheet / ワークシート

- **Use:** fill this worksheet with the user’s evidence.
- **Unknowns:** retain “Not supplied” until information is available.
- **Status:** distinguish proposed content from an agreed decision.

| Section | What to record | Working content |
|---|---|---|
| Competency questions | Role; question; decision; evidence label; required answer path. | Not supplied |
| Events and vocabulary | Ordered event; actor; objects; synonyms; ambiguous terms. | Not supplied |
| Objects | Identity; meaning; properties with unit/source notes; existing ID if updating. | Not supplied |
| Relationships and actions | Source; verb; target; optional join entity; changed object; preconditions; intended writeback. | Not supplied |
| Data map | Object; system; table; identifier; join key; history; gap; answer owner. | Not supplied |
| Tests | Question path; missing step; hypothetical action; affected objects; unverified assumptions. | Not supplied |
| Builder handoff | Supported definitions; preserved IDs/keys; unresolved worksheet items; next questions. | Not supplied |

## Before handoff / 引き継ぎ前

- Each competency question can be traced or has an explicit gap.
- Source IDs and terminology have not been fabricated.
- Actions remain definitions until a real execution system exists.
