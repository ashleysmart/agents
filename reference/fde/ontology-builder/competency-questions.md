# Competency questions / モデルが答える問い

- **Use:** decide what the ontology needs to represent before adding entities.

## Form / 書き方

- Name the business role that asks the question.
- State the decision the answer informs.
- Write the question using the customer’s vocabulary.
- Identify the required entities, relationships, properties, and time context.
- Label wording and roles as assumed when they have not been supplied.
- Start with a few useful questions for an open-ended sketch.
- Preserve a larger explicit question set when the user supplied one.

## Test / 確認

- Walk from the question’s starting object to the information needed for an answer.
- Mark a missing relationship, ambiguous property, unavailable source, or unrepresented history as a specific gap.
- Record the role who can resolve the gap.
- Revisit the question when a proposed object does not support any requested decision.
- Do not remove intentionally modeled technical entities merely because the business-question default does not apply.

## Output / 成果物

- Question ID; role; decision; question; evidence label; required path; gap; answer owner.
